# Arsip: versi Docker + MySQL

Folder ini berisi versi pertama dashboard yang dirancang untuk homelab (Node.js + MySQL di Docker). Versi yang dipakai sekarang berjalan di Cloudflare Workers + D1 (lihat README di folder utama).

Disimpan hanya sebagai cadangan kalau suatu saat ingin pindah ke homelab lagi. Untuk menjalankannya, file di sini perlu dikembalikan ke folder utama bersama folder `public/` dan `data/`.
